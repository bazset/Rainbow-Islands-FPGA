# Rainbow Islands PCB Explorer / レインボーアイランド基板マップ

An interactive BAZSET research map for the Taito Rainbow Islands arcade PCB **K1100277A / J1100128A**.

**[Open the interactive GitHub Pages site](https://bazset.github.io/Rainbow-Islands-FPGA/)**

- English (default) and Japanese / 日本語 language selector.
- Mobile-friendly chip details: tap any mapped chip or chip name to open a readable bottom-sheet panel, scroll within it, then dismiss using ×, the dark backdrop, or Escape. Desktop continues to use the side details panel.
- Original component-side and solder-side photographs **generously provided by Ben — thank you, Ben!** Search, zoom, chip selection, original B22 circuit links, and MiSTer FPGA source-module cross-reference by **filename only**.
- **No FPGA source code, private RTL excerpts, personal computer paths, release files, KiCad sheets or credentials are included in this static publication.**
- Physical chip/region annotations contain estimates clearly marked with dashed amber boxes. The solder-side copper nets are **not** electrically verified and are intentionally not overlaid.
- **Board revisions are different:** the photographed target is B22 K1100277A; Jotego's Ulf Skutnabba KiCad project is Rainbow Islands Extra **K1100319A**, provided as an external reference, not a verified same-board schematic.
- MAME and board repair resources are linked from the dashboard as technical references, not redistributed.

This is a public research snapshot. To refresh from the local private engineering explorer, run `package_public.py`, verify `test_public_site.js`, and copy **only** the listed six site files (index.html, app.js, locale_ja.js, site_data.js, front.webp, back.webp) into the GitHub Pages branch. The website does not automatically reflect unsaved development changes.
